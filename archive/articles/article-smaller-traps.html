Smaller traps worth writing down

Five small failures that each cost more than they should have. None of them was hard to fix; all of them were hard to see.

five failures, one page

  • A single-file bind-mount serves a stale inode. Editing a config on the host and reloading inside the container changed nothing — the mount still pointed at the old file, and nginx -t happily validated it, which is the tell that you are testing the wrong thing. Mount the directory, or recreate the container.
  • docker compose up resurrects what you retired. Both depends_on and a start script with no service arguments will pull a removed dependency back up. Retired services now sit behind a non-default profile, invisible to a plain up -d.
  • A container restart does not re-read env_file. Only a recreate picks up changes. This bit twice, through a Django ALLOWED_HOSTS setting.
  • Angular's emulated encapsulation does not protect a component from global selectors. A landing page reused class="steps"; the app's global stylesheet already had .steps li { display: flex } for its own stepper, and every text run in the list became a separate flex item. It compiled cleanly and every string check passed. Namespace the classes you introduce.
  • Write the string before you open the file. open(path, "w").write(<expression that raises>) truncates the file the instant open() is called, because the argument is evaluated afterwards. A formatting error silently emptied an 8,828-byte stylesheet.
